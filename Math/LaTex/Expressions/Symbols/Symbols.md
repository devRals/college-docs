## Math Symbols

| Name               | Symbol        | Usage         |
| ------------------ | ------------- | ------------- |
| **Addition**       | $+$           | `+`           |
| **Subtraction**    | $-$           | `-`           |
| **Multiplication** | $\times$      | `\times`      |
| **Division**       | $\div$        | `\div`        |
| **Fraction**       | $\frac{a}{b}$ | `\frac{a}{b}` |
| **Percent**        | $\%$          | `\%`          |

## Greek Letters
For capital letters just make the first letter after the "\\" capital

| Name      | Symbol            | Usage    |
| --------- | ----------------- | -------- |
| **Alpha** | $\alpha$          | `\alpha` |
| **Beta**  | $\beta$           | `\beta`  |
| **Theta** | $\theta$ $\Theta$ | `\theta` |
| **Delta** | $\delta$ $\Delta$ | `\delta` |
| **Zeta**  | $\zeta$           | `\zeta`  |
| **Sigma** | $\sigma$ $\Sigma$ | `\sigma` |
| **Nabla** | $\nabla$          | `\nabla` |
| **Gamma** | $\gamma$ $\Gamma$ | `\gamma` |
| **Pi**    | $\pi$ $\Pi$       | `\pi`    |
| **Phi**   | $\phi$ $\Phi$     | `\phi`   |
| **Aleph** | $\aleph$          | `\aleph` |
